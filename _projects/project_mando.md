The project's primary objective is to detect vulnerabilities in the source code and bytecode of smart contracts, both at the coarse-grained contract-level and fine-grained line-level, with a high degree of accuracy. The core engines of the MANDO project are constructed on the foundation of state-of-the-art heterogeneous deep graph learning methodologies.

Led by Dr. Hoang H. Nguyen, MANDO has developed as a continuing research series, progressing from graph embeddings to heterogeneous graph transformers and LLM-enhanced vulnerability detection:

- **MANDO** — Multi-level heterogeneous graph embeddings for fine-grained detection of smart-contract vulnerabilities (IEEE DSAA 2022).
- **MANDO-GURU** — Vulnerability detection for smart-contract source code by heterogeneous graph embeddings, tool demonstration (ACM ESEC/FSE 2022).
- **MANDO-HGT** — Heterogeneous graph transformers for smart-contract vulnerability detection (IEEE/ACM MSR 2023).
- **MANDO-LLM** — Heterogeneous graph transformers with large language models for smart-contract vulnerability detection, first-authored by Nhat-Minh Nguyen (ACM TOSEM 2026).
